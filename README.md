# ansi3d

A little thing I've been working on. Not sure how far it will go.

# Getting started

Make sure you have SDL 1.2 installed, since that's what I started out with, but I am planning to add plenty more backends, other than SDL 1.2.

```
# Make sure to edit the top of the Makefile!!!
make -j1
# To make example:
make example
./example
```
